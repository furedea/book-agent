# CHANGELOG

All notable changes to this project will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2025-08-15

### Added

- Initial release of the `/book-agent:book2agent` custom slash command.
- Core functionality for analyzing text from technical resources.
- Feature to generate structured knowledge bases including "Core Principles," "Key Techniques," and "Anti-patterns."
- Automatic generation and saving of Sub Agent definition files (`.md`).
- Interactive workflow to handle user approval and modification requests.
- Support for a `-y` flag for non-interactive execution.
